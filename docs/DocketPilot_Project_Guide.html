DocketPilot project guide

An Agentic AI System for Indian Legal Research, Drafting, Anti-Hallucination Verification and Case Management

In one sentence: DocketPilot is a web app where a lawyer uploads case papers or asks a question, and a team of AI "agents" finds the right Acts and judgments, writes the answer or draft, and checks every citation against real judgments before the lawyer sees it, while hiding client names from the AI.

The whole project lives in one folder on the laptop: D:\docket pilot\. A copy of the code (not the data or secrets) is on GitHub: github.com/srigaran2020/DocketPilot.

Three things run when the app is on:

  1. Docker Desktop runs four storage programs (databases) in the background.
  2. The DocketPilot server (Python) runs the web app at http://127.0.0.1:8000. Started by start.ps1.
  3. Groq, a cloud AI service on the internet, answers when DocketPilot asks it to read or write. It only ever receives masked text.

8. Follow one request through the files

A. The lawyer asks a legal question in the chat

  1. Typed in the chat on web\index.html, sent to the server.
  2. api\assistant.py decides it is a question (not a draft or a date).
  3. chat.py masks names using privacy\redact.py.
  4. retrieval\search.py finds the 6 best judgment passages (PostgreSQL + Qdrant) and the matching Act sections.
  5. llm\groq_provider.py sends the masked question and sources to Groq; the AI must tag every legal statement with a source.
  6. verification\engine.py checks every citation; verification\correct.py fixes or removes wrong ones.
  7. Real names are put back and the answer appears with "✓ N checked".

B. The lawyer uploads a case paper

  1. 📎 in the chat or case page → api\casefiles.py reads the text.
  2. privacy\redact.py masks names; the lawyer reviews and confirms.
  3. casefile.py reads the case number on the laptop and files the paper into the right case (table matters).
  4. Real names go to vault\ (encrypted); masked text goes to table matter_documents.
  5. casefile.py asks the AI for every dated event; each date is kept only if its words appear in the paper → table reminders → Calendar.

C. The lawyer asks for a draft

  1. api\matters.py starts the agent team in agents\graph.py.
  2. agents\nodes.py runs: Orchestrator → Document analysis → Research → Drafting → Verification → Strategy & risk → Monitoring.
  3. The graph pauses; the lawyer reviews on the draft page and approves.
  4. drafting\docx_out.py writes the Word file with real names from vault\ into data\outputs\.

10. Examiner questions, with where to point

Where is the knowledge base stored?

In PostgreSQL (tables cases, chunks, acts, section_versions) inside Docker, plus a vector index in Qdrant (collection chunks_all). Source PDFs: data\raw\. Built by docketpilot\ingestion\.

Where did the data come from? Is it legal to use?

Supreme Court and High Court judgments from the AWS Open Data Registry (CC-BY-4.0 licence); Acts from India Code (Government of India). Code: ingestion\download.py, knowledge\statutes.py.

How many judgments and Acts?

16,318 judgments with full text (Supreme Court 2015-2026 and five High Court benches 2023-2024), 48,168 Supreme Court cases for citation checks, 35 Central Acts with 4,832 sections, 430,882 passages, 372,122 in the vector index.

Where are the agents? How many?

Seven, in docketpilot\agents\nodes.py, connected in agents\graph.py using LangGraph.

How do you stop the AI from inventing cases (hallucination)?

Three ways: (1) the AI may only use retrieved sources and must tag each legal statement (prompts\chat_v1.md); (2) every citation is checked against real judgments (verification\engine.py); (3) wrong ones are corrected or removed before the lawyer sees them (verification\correct.py). Result: 0 fabricated citations in our test vs 5.6% for the same AI alone.

Which AI model do you use? Where does it run?

openai/gpt-oss-120b on Groq's cloud. Code: llm\groq_provider.py. Up to 4 keys with automatic switching.

How is client data protected?

Names and ID numbers are masked on the laptop before any AI call (privacy\redact.py); real names are encrypted in vault\ (privacy\vault.py); only masked text is stored in the database; passwords are Argon2-hashed; every account has its own private workspace.

What is RAG and where is it?

Retrieval-augmented generation: first find relevant documents, then let the AI answer only from them. Retrieval is retrieval\search.py; generation is in chat.py and agents\nodes.py.

What is the "vector index" and why a GPU?

Each passage is turned into a list of 384 numbers that captures its meaning, so similar meanings can be found even with different words. Built once with retrieval\index.py on the laptop's RTX 3050 GPU (~430 passages per second, versus ~5 on the CPU).

Where is the front end? Which framework?

docketpilot\web\index.html, one file of plain HTML and JavaScript (no React), served by FastAPI.

Where is the database structure defined?

migrations\versions\0001 to 0004, applied by Alembic when start.ps1 runs.

How do you test it? Where are the results?

242 automated tests in tests\ (run check.ps1). Benchmarks in docketpilot\evaluation\; results in reports\EVALUATION_REPORT.md and reports\COMPARISON.md; charts in reports\figures\.

How does the calendar get hearing dates?

casefile.py asks the AI for every dated event in a paper and keeps a date only if its exact words appear in the paper; dates are saved in table reminders. "When is my next hearing?" is answered from that table with no AI.

Can it draft any document?

Yes: any document type through the general workflow in agents\nodes.py (prompt prompts\drafting_general_v1.md); cheque-bounce notice and complaint use fixed templates in data\templates\.

How do you start the project?

Open Docker Desktop, then run start.ps1, then open http://127.0.0.1:8000.

Why were design choices made (e.g. why Groq, why no React)?

Every decision and its reason is in docs\DECISIONS.md (decisions 1 to 33).

What are the limitations?

No lawyer reviewed the legal data; 3.2% of personal details slip through masking in tests (the lawyer's review step is the safeguard); free AI tier limits daily use; no OCR for scanned papers; not yet hosted online.

11. Words to know

AgentA program step that does one job (read, research, draft, check) and passes its result on.
HallucinationWhen an AI states something false with confidence, e.g. a case that does not exist.
CitationThe reference to a judgment, e.g. "2020 INSC 631".
Chunk / passageA small piece of a judgment, about a paragraph or two, used for search.
Embedding / vectorA list of numbers that represents the meaning of a text.
RAGRetrieval-augmented generation: search first, then answer from what was found.
Masking / redactionReplacing personal details with placeholders like PERSON_1.
EndpointA web address on the server that does one thing (e.g. /auth/login).
Docker volumeA storage area managed by Docker where a database keeps its files.
MigrationA numbered step that creates or changes database tables.
TokenA piece of a word; AI services count and charge by tokens.
